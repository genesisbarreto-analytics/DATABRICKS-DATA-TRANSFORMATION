# 📁 Case Studies

## 01 — Data Platform Migration | Incremental Pipelines

Proyecto actualmente en desarrollo orientado a trasladar múltiples procesos de preparación y transformación de datos hacia Databricks.

El trabajo incluye:

- Creación de notebooks en Scala.
- Adaptación de lógica SQL hacia Spark SQL.
- Extracción desde distintas fuentes.
- Aplicación de filtros y reglas de negocio.
- Consolidación de DataFrames.
- Validaciones antes de escritura.
- Construcción de tablas Delta.
- Validaciones posteriores a la carga.
- Automatización mediante Databricks Jobs.
- Seguimiento de ejecuciones y errores.

### Tecnologías

`Databricks` `Scala` `Apache Spark` `Spark SQL` `Delta Lake` `Databricks Jobs`

# ⚙️ Automatización

Parte de los notebooks se están incorporando progresivamente a **Databricks Jobs** para automatizar su ejecución.

Actualmente estoy aplicando:

- Ejecuciones manuales de validación.
- Programación mediante schedules y triggers.
- Seguimiento de estados `Succeeded` y `Failed`.
- Revisión de logs y métricas.
- Corrección y reejecución de procesos.
- Monitoreo de duración de las cargas.
